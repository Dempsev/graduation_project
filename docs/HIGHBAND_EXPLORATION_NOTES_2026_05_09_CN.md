# 高频目标频带补样探索纪要（2026-05-09）

本文档用于给后续对话或写作接力参考，记录本轮围绕 `5.7 弱频带/高频带设计结果分析` 展开的探索过程、关键结果和论文写法建议。

## 1. 背景与问题

在原 5.5 典型案例中，高频目标带主要依赖 `ep253_step54` 在 `220-260 Hz` 与 `240-280 Hz` 两个相邻频带上的覆盖表现。该设置可以用于说明“同一结构在相邻高频目标带下的迁移表现”，但不宜被写成高频目标带的最终最优结果。

进一步检查发现：

- 手工叠加的形状原型（如 `bilobe + asym`、`bilobe + notch`、`asym + notch`）虽然几何和接触稳定，但主要把带隙维持在约 `160-190 Hz`，没有有效推入更高目标频带。
- 因此，高频补样不应继续依赖“更复杂随机形状”，而应转向“高潜力结构族 + 局部参数迁移”。

核心判断：

> 高频有效候选不是简单由形状复杂度决定，更可能集中在少数高潜力结构族和参数邻域中。预测模型在高频稀疏区只能作为弱辅助，最终判断必须依赖 COMSOL 真实频散计算。

## 2. 已完成实验概览

本轮实际完成三组实验：

| `highband_param_migration_probe_v1` | 围绕高频近邻结构做第一轮参数迁移 | 42 点 | 成功找到 `200-240`、`220-260`、`240-280 Hz` 有效覆盖候选 |
| `highband_param_migration_round2_v1` | 对第一轮有效线索做二轮精扫 | 24 点 | 进一步确认 `ep29`、`ep253`、`ep209`、`ep218` 等高频线索 |

## 3. 实验一：形状叠加机制探索

### 3.1 候选生成

候选包括：

- `bilobe + asym`
- `bilobe + notch`
- `asym + notch`
- `ep29_step96` 自然 snake 对照

相关文件：

- 候选目录：`data/shape_mechanism_combo_pilot_v1/`

- 结果分析：`data/shape_mechanism_combo_pilot_v1/analysis/shape_mechanism_combo_targetband_analysis_v1.csv`

### 3.2 结果

COMSOL 运行结果：

- 21 个验证点全部求解成功。
- 几何失败：0。
- 接触失败：0。
- 叠加候选的 `gap34` 多数有正增益，但带隙主要落在约 `159-188 Hz`，没有覆盖 `200-240`、`220-260`、`240-280 Hz`。

唯一有高频苗头的是自然 snake 对照：

| 目标频带 | 结构 | 机制 | 覆盖率 | 覆盖宽度 / Hz | 有效带隙范围 / Hz |
|---|---|---|---:|---:|---|
| `200-240` | `ep29_step96_contour_xy` | natural snake control | 0.282 | 11.28 | 228.72-499.09 |

结论：

> 简单叠加形状原型并不能自动解决高频稀疏问题。相比手工叠加机制，自然生成的高潜力 snake 结构反而更值得围绕其参数邻域继续探索。

## 6. 写入论文时的建议表述

### 6.1 5.5.2 如何处理

5.5.2 不建议整体推翻。原表 5-1 仍可作为“第一组典型案例”的基准案例，但要避免写成最终最优结果。

建议补充一句：

> 表 5-1 中案例主要用于支撑本节典型频散曲线、带边模态和局部稳定性分析，并不表示本文在各目标频带下获得的最终最优候选。对于较高频目标带，后文还将结合高潜力结构族的局部参数迁移进一步补充验证结果。

### 6.2 5.7 的主线建议

5.7 可改写为：

> 高频目标频带设计不是单纯依赖复杂随机形状，而更适合采用“真值反查 + 高潜力结构族 + 局部参数迁移”的补样策略。

可写入的核心结论：

1. 简单形状叠加能够保持几何和求解稳定，但未能稳定将带隙迁移到高频目标带。
2. 通过已有真值结果反查，可发现少数高频潜力结构族。
3. 围绕这些结构族进行局部参数迁移，可以获得更高的目标频带覆盖。
4. 预测模型在高频稀疏区不宜作为最终判据，只能作为粗筛或辅助排序信息；最终有效性仍由 COMSOL 真实频散计算确认。

可直接写的句子：

> 结果表明，高频目标频带下的有效候选并非随结构复杂度单调增加。手工叠加的复杂形状虽然具有较好的几何可行性，但其主要带隙仍集中在中频区域。相比之下，围绕高潜力结构族进行局部参数迁移能够更有效地获得高频目标带覆盖，说明高频补样更依赖结构族邻域中的定向搜索，而不是完全随机的形状扩展。

## 7. 注意事项与风险

1. `gap34_gain_Hz` 不能直接等同于目标频带覆盖。必须使用由频散表重新计算得到的任意相邻分支目标带覆盖率。
2. `ep248` 第一轮在 `220-260 Hz` 覆盖率达到 0.791，但二轮中心点仅约 0.357，说明该结构或分析口径存在敏感性。写作时可弱化 `ep248`，主推 `ep253`。
3. `ep209` 第一轮曾出现 `240-280 Hz` 覆盖率 1.000，二轮同类参数为约 0.655。写作时应写“有效覆盖”或“显著覆盖”，不要过度强调“稳定完全覆盖”。
4. `ep29` 的 `200-240 Hz` 结果较稳，两轮均有强或接近强覆盖，是最适合作为 `200-240 Hz` 高频补样代表的结构。
5. `ep205` 在减小 `r0` 时出现接触失败，不建议作为主文代表案例。

## 8. 后续建议

如果继续推进，建议不要再大规模随机搜索，而做两件事：

1. 导出代表结构的频散图：
   - `ep29_step96 / r0=0.0112` 对应 `200-240 Hz`
   - `ep253_step54 / a1=0.47, r0=0.0115` 对应 `220-260 Hz`
   - `ep209_step63 / a1=0.52` 或 `a1=0.52, a2=-0.13` 对应 `240-280 Hz`

2. 做一张高频补样汇总表：
   - 目标频带
   - 结构编号
   - 参数设置
   - 覆盖率
   - 覆盖宽度
   - 有效带隙范围
   - 备注（稳定/敏感/接触风险）

这两项足以支撑 5.7 的高频结果分析。
