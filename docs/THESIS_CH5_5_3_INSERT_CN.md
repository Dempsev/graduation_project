### 5.5.3 不同目标频带案例对比分析

为进一步比较本文方法在不同目标频带条件下的表现，本节选取四个具有代表性的目标频带案例进行对比分析。所选案例覆盖 180--220 Hz、200--240 Hz、220--260 Hz 和 240--280 Hz 四个目标频带，其中 180--220 Hz 可作为中频目标频带代表，200--240 Hz 可用于观察相邻频带过渡条件下的候选表现，220--260 Hz 和 240--280 Hz 则用于分析较高频目标条件下的候选发现能力。四个案例对应的结构分别为 ep248_step27、ep193_step51 和 ep253_step54，其中 ep253_step54 同时出现在 220--260 Hz 与 240--280 Hz 两个高频目标频带中，用于说明同一结构在相邻高频目标下的可迁移性。

图 5-x 给出了四个典型案例中心候选的频散曲线对比。可以看出，不同目标频带对应的有效带隙位置并不完全相同。对于 band180_220_ep248，带隙边界位于约 179.77 Hz 和 226.44 Hz 附近，能够覆盖 180--220 Hz 目标区间；对于 band200_240_ep193，带隙边界约为 197.86 Hz 和 259.60 Hz，覆盖范围向较高频方向移动；对于 band220_260_ep253 与 band240_280_ep253，带隙边界分别位于约 208.43 Hz 和 275.92 Hz 附近，说明该结构在高频目标区间附近具有较明显的带隙响应。上述结果表明，目标频带条件改变后，候选结构的价值并不是由单一整体评分决定，而是取决于其带隙边界与给定目标频带之间的对应关系。

图 5-x 给出了四个典型案例在下带边和上带边处的模态振型。由图可见，不同目标频带案例的带边模态呈现出不同的局域化特征。部分案例的位移响应主要集中在夹杂体边界和局部连接区域附近，说明带隙形成与局部几何扰动及边界耦合有关；部分高频案例在单胞外边界和局部收缩区域呈现更明显的振型变化，反映出较高频目标下弹性波传播状态的改变。该结果说明，候选结构进入目标频带并不是简单的频率数值匹配，而是伴随带边模态形态的变化。

为进一步观察不同案例的局部能量参与方式，图 5-x 给出了对应的应变能密度分布。可以看出，较高应变能区域主要出现在夹杂体边界、局部连接区以及几何曲率变化较明显的位置。这些区域与带边模态中的局部位移集中位置基本对应，说明目标频带附近的带隙响应与局部变形能量聚集密切相关。对于 band180_220_ep248，能量分布更突出地反映出低频至中频范围内的局部边界参与；对于 ep253 相关高频案例，能量集中区域在上下带边之间具有一定差异，说明同一结构在相邻高频目标下仍可能通过不同的带边模态参与目标频带形成。

若进一步观察 von Mises 等效应力分布，可以发现应力集中主要出现在局部连接和几何突变区域附近。虽然整体应力场相对平缓，但局部区域仍存在可辨识的应力集中现象。这说明候选结构中的局部细节并非单纯的几何装饰，而可能参与带边模态形成、局部能量聚集和弹性波传播路径调控。因此，物理场分布为频散曲线中的目标频带结果提供了进一步解释。

除四个正向案例外，本节还比较了典型结构在不同目标频带之间的迁移表现。图 5-x 给出了 ep248_step27、ep193_step51 和 ep253_step54 三个结构在 180--220 Hz、200--240 Hz、220--260 Hz 和 240--280 Hz 目标频带下的覆盖率热图。结果表明，同一结构对不同目标频带的适配程度存在明显差异。例如，ep248_step27 在 180--220 Hz 目标频带下覆盖率达到 1.000，但在 220--260 Hz 和 240--280 Hz 下分别降至 0.161 和 0.000，说明该结构更适合作为低频或中频案例，而不适合作为高频目标候选。相反，ep253_step54 在 220--260 Hz 和 240--280 Hz 下覆盖率分别为 1.000 和 0.898，但在 180--220 Hz 下仅为 0.289，说明该结构更适合高频目标条件。

上述反例说明，目标频带条件预测的必要性在于：同一个候选结构并不存在对所有目标频带都有效的统一价值，其设计意义必须放在具体目标频带下判断。若只采用无条件预测或总体带隙评分，容易将某一频带下表现良好的结构误判为所有频带下均具有优势。本文采用结构参数、结构族和目标频带共同作为输入，正是为了表达这种“结构--目标频带”之间的条件对应关系。

综合来看，四个正向案例说明本文方法能够在多个目标频带下筛选出具有实际带隙响应的候选结构；两个反向迁移现象则说明，候选结构的有效性具有明显目标频带依赖性。频散曲线给出了目标频带覆盖结果，带边模态和应变能密度分布解释了带隙形成时的局部物理响应，覆盖率热图则进一步说明了条件预测相对于普通结构评分的必要性。因此，本节案例分析不仅用于展示典型结果，也为本文目标频带条件预测和预测驱动候选筛选方法提供了具体物理依据。
