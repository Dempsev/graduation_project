## 图 4-x Family-CV 与 leave-one-band 验证划分示意图

建议插入位置：第 4 章 `4.3 训练与验证设置` 中，放在解释 family-CV 与 leave-one-band 的段落之后、表 4-3 之前。

建议图题：

**图 4-x Family-CV 与 leave-one-band 验证划分示意图**

图前正文：

由于本文的数据样本同时具有结构族属性和目标频带属性，若仅采用普通随机划分，模型可能在训练集和验证集中同时看到相似结构或相同目标频带条件，从而高估预测器在真实候选筛选场景中的可用性。为更严格地检验模型是否具备进入后续逆向设计流程的资格，本文采用 family-CV 和 leave-one-band 两类互补验证策略。前者按结构族留出验证，主要考察模型面对未见结构族时的迁移能力；后者按目标频带留出验证，主要考察模型面对未见目标频带窗口时的外推边界。

图后正文：

如图 4-x 所示，family-CV 与 leave-one-band 的区别并不只是数据划分方式不同，而是分别对应两类泛化问题。family-CV 更贴近“在既定目标频带目录内，模型能否迁移到新的结构族”；leave-one-band 则更贴近“当目标频带条件发生变化时，模型输出是否仍具有参考价值”。因此，本文在解释第四章结果时不将单一验证指标作为模型可用性的全部依据，而是综合分类性能、回归质量、top-k 候选质量和概率校准情况判断预测器能否作为候选筛选前端。

如果正文空间紧张，可以使用精简版：

图 4-x 给出了本文两类验证划分的基本逻辑。family-CV 从结构族维度检验模型迁移能力，leave-one-band 从目标频带维度检验模型面对未见频带窗口时的边界表现。二者共同约束模型评价，避免普通随机划分高估条件预测器的真实候选筛选价值。
