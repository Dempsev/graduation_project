# 三篇参考论文可借鉴点整理

本文档分析老师给出的三篇参考论文，目标是提炼“论文结构和写法”上的可借鉴点，并映射到当前 COAD 论文修改。

参考文件：

- `output/doc/机器学习增强的梁式加强筋组合结构拓扑优化研究_刘晏榕.pdf`
- `output/doc/基于改进BP神经网络的热管冷却堆堆芯结构优化研究_肖源剑.pdf`
- `output/doc/基于深度学习的太赫兹超表面图形化结构设计_柯振东.pdf`

## 一、总判断

这三篇论文共同说明一件事：机器学习辅助工程设计类论文，不需要把所有工作写得很玄，也不需要把竞争说得很强。更稳的写法是：

1. 先把工程对象和具体困难说清楚。
2. 再说明为什么需要机器学习作为加速或筛选工具。
3. 然后建立数据集或仿真样本。
4. 训练代理模型或预测模型。
5. 用优化/搜索方法得到候选方案。
6. 最后用仿真或真实物理计算验证结果。

这个结构和当前 COAD 论文主线高度一致。你的论文应写成：

> COMSOL 物理真值与目标频带数据集 -> 条件预测模型 -> 候选筛选与局部精修 -> Stage4 真实验证。

不要写成：

> 我做了很多脚本、很多路线、很多图表，所以形成了可解释可复现可验证闭环。

## 二、刘晏榕论文可学什么

题目：机器学习增强的梁式加强筋组合结构拓扑优化研究。

### 结构特点

该文是典型“方法建立 + 模型构建 + 数值算例 + 扩展应用”的写法：

1. 绪论
2. 机器学习增强的梁式加强筋组合结构拓扑优化方法
3. 机器学习预测模型的构建
4. 优化数值方法和算例
5. 机器学习增强的组合结构拓扑优化设计
6. 结论与展望

### 可借鉴点

第一，它的第一章不把“研究问题”写得很抽象，而是落到一个具体困难：多类型单元连接导致 MPC 方程反复建立与求解，优化效率低。你的第一章也应该落到一个具体困难：

> 指定目标频带下，候选结构空间大，真实 COMSOL 验证成本高，普通无条件预测不能回答“这个结构对这个 band 是否有用”。

第二，它把“机器学习模型构建”单独成章，先讲数据集生成、网络结构、数据预处理，再进入优化算例。你的论文也应该把“条件预测模型”单独成章，不要和逆向设计方法混在一起。

第三，它的数值算例不是堆所有结果，而是按“简单算例 -> 复杂算例 -> 工程算例”推进。你的第五章可以学这个顺序：

1. 条件预测性能。
2. 典型目标频带案例。
3. 基线对比。
4. 弱频带案例。
5. Stage4 真实验证。

第四，它的结论写法是“模型结论、方法框架结论、扩展应用结论”三条，而不是抒情式总结。你的结论也应该写三条：

1. 条件预测模型具有候选筛选价值。
2. 预测驱动搜索能提高候选质量。
3. COMSOL 验证说明流程在当前频带目录和结构族内成立。

### 不建议照学

- 它是硕士论文，理论推导和算例数量比本科论文更重，你不用照这个体量扩写。
- 它有“创新点”小节，但老师已经说你这边创新点可以弱化，所以你可以改成“主要工作”。

## 三、肖源剑论文可学什么

题目：基于改进 BP 神经网络的热管冷却堆堆芯结构优化研究。

### 结构特点

该文和你的论文最像。它的结构是：

1. 绪论
2. 堆芯材料界面热阻特性研究及堆芯热力耦合分析
3. 基于 BP 神经网络的固态堆芯热力性能预测
4. 基于 NSGA-II 算法的堆芯关键结构优化
5. 结论与展望

这其实就是：

> 物理/仿真基础 -> 机器学习代理模型 -> 优化设计 -> 仿真验证。

你的论文可以直接套同类骨架：

1. 绪论
2. 声子晶体目标频带问题定义与物理真值数据基础
3. 面向目标频带的条件预测模型
4. 预测驱动的目标频带逆向设计方法
5. 实验结果与 COMSOL 验证
6. 总结与展望

### 可借鉴点

第一，它把“物理基础/仿真基础”放在机器学习之前。这点非常重要。你的论文也要先讲 COMSOL 频带计算、带隙提取、target band 标签，再讲模型。

第二，它写机器学习不是空讲模型，而是写清楚：

- 输入输出节点怎么选。
- 数据怎么预处理。
- 样本怎么自动采集。
- 模型评价指标是什么。
- 和其他代理模型怎么对比。

你的第三章可以对应写：

- 输入：结构参数、结构族、目标频带。
- 输出：开启概率、覆盖质量。
- 数据：target-band 参数化数据集。
- 指标：F1、balanced accuracy、R2、top-k lift、校准关系。
- 对比：family-CV 和 leave-one-band。

第三，它的优化章写得很清楚：先定义优化目标和设计变量，再讲算法，再讲 Pareto 结果，最后把优化参数导回 ABAQUS 仿真验证。你的第四/第五章也应该这样写：

1. 定义目标频带设计任务。
2. 定义候选评分。
3. 说明局部精修参数和约束。
4. 输出 validation manifest。
5. 导回 MATLAB/COMSOL 真实验证。

第四，它很重视“预测值和仿真值对比”。这是你必须学的。你的结果章应增加或强调：

- 预测候选的 score/cover 与真实 COMSOL gap/cover 的对比。
- Stage4 验证中几何有效、接触有效、求解成功、正增益的数量。
- 预测模型只是筛选，不是最终判定。

### 最适合你照抄结构的地方

把当前论文的第二章和第三章合并，形成类似肖源剑第二章的“物理真值与数据基础”章；把当前第四章改成类似肖源剑第三章的“机器学习预测模型”章；把当前第五章改成类似肖源剑第四章的“优化/搜索与验证”章。

### 不建议照学

- 它的第一章文献综述仍偏长，你可以学结构，不要学篇幅。
- 它有大量热阻实验细节，你没有实验测量部分，不要硬补。

## 四、柯振东论文可学什么

题目：基于深度学习的太赫兹超表面图形化结构设计。

### 结构特点

该文是“正向预测 -> 逆向设计 -> 应用扩展”的深度学习设计论文：

1. 绪论
2. 相关理论与技术基础
3. 基于卷积神经网络的超表面图像-光谱预测方法
4. 基于生成对抗网络的超表面图形逆向设计方法
5. 多频可调谐吸收器的逆向设计方法应用
6. 总结与展望

### 可借鉴点

第一，它非常清楚地把正向预测作为逆向设计的基础。你的论文也应该强调：

> 条件预测模型不是终点，而是逆向设计的前端筛选器。

第二，它每个方法章都有“动机与优势”。这个可以学。你的第三章开头可以写：

> 传统无条件预测只能判断结构整体性能，不能回答指定目标频带下的可用性。因此需要构建 target-band 条件预测模型。

你的第四章开头可以写：

> 条件预测分数不能直接作为物理结论，因此需要将其转化为候选筛选、局部精修和 COMSOL 验证流程。

第三，它把“数据集构建、网络架构、训练策略、验证指标”分得很清楚。你的模型章也要这样分，不要把指标、图表、模型边界揉在一起。

第四，它的逆向设计章强调多解性和生成验证。你这里可以对应讲“同一目标频带可能存在多种结构族候选”，所以 shape-aware candidate construction 是合理的，不是随便加的模块。

### 不建议照学

- 这篇 AI 味比较明显，很多“突破性”“显著意义”“关键技术支撑”等词你不要学。
- 它的第一章背景写得比较飘，你现在最需要的是更具体、更工程化。
- 它偏生成式模型，你不是直接生成结构图像，不要把你的方法写成“端到端逆向设计器”。

## 五、三篇论文共同值得学的地方

### 1. 第一章都在 8-10 页内完成收束

三篇论文第一章都不是无限展开。它们一般都是：

- 背景意义
- 国内外研究现状
- 本文研究思路及目标/结构安排

你当前第一章需要压缩，尤其背景与现状不要写太多“泛泛而谈”的句子。

### 2. 章节标题都很具体

它们不会写“实验块作用定位”“证据链”这种内部分析标题，而是写：

- 数据集构建
- 预测模型构建
- 优化框架
- 仿真验证与性能分析
- 本章小结

你的标题也应尽量具体：

不要写：

> 条件预测器结果在实验链条中的作用

建议写：

> 条件预测模型性能分析

不要写：

> 真实物理验证结果

建议写：

> Stage4 候选结构 COMSOL 验证结果

### 3. 图表标题都说明对象

参考论文的图名通常包含对象和含义，例如“自动化样本数值模拟流程图”“PSO-BP 和 BP 神经网络预测值与真实值对比图”“拓扑优化流程”。你的图名要避免：

- 图 1-1
- 图 6-14
- 实验结果证据链
- 作用定位示意图

改成：

- 图 1-1 目标频带条件预测与预测驱动逆向设计总体流程
- 图 5-6 Stage4 候选结构真实验证漏斗
- 图 5-7 预测候选与 COMSOL 验证结果对比

### 4. 机器学习都被写成工具，不是神话

刘文：机器学习用于预测耦合单元刚度阵，减少 MPC 方程求解成本。
肖文：BP 网络作为热力性能代理模型，服务多目标优化。
柯文：深度学习用于光谱-结构映射和逆向生成。

你的写法也应是：

> 条件预测模型用于候选筛选和排序，最终结构性能由 COMSOL 验证。

不要写成：

> 预测器构成可解释、可复现、可验证的目标频带逆向设计闭环。

后者太像报告总结。

### 5. 结论都按工作模块分条

结论不是重新写一遍背景，而是按模块总结：

- 数据/物理基础结论
- 模型预测结论
- 优化/搜索结论
- 仿真验证结论

你的结论也按这个来写。

## 七、给当前论文的直接修改动作
