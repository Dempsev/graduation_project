# 论文急救版修改方案

本文档面向当前 `output/doc/total (5).pdf`。目标不是推翻已有工作，而是把当前“技术报告式堆叠”改成一篇更像学位论文的结构：先钉住研究对象和问题，再说明方法，再用实验链条支撑结论。

## 一、总判断

当前论文不是没救，主要问题是表达和组织层面的：

- 研究对象出现得太晚，第一章前半部分通用背景偏多。
- “本文”“并非”“需要强调的是”“不是……而是……”等模板句密度高，读起来像 AI 报告。
- 第二章、第三章都在定义对象和数据基础，边界和真值逻辑重复，可合并。
- 第七章和第八章内容大量重复，可压缩为最后一章的“不足与展望”。
- 第六章图表编号和旧引用不一致，部分图名过空，例如“图 1-1”“图 6-14”。
- 图表更像内部汇报材料，部分坐标、指标、标签没有用论文语言解释。

修改策略：保留核心技术主线，重排章节，压缩套话，重写开头和章末小结，统一图表编号与图表说明。

## 九、AI味机械清理清单

全文搜索并重点处理以下词：

- 本文
- 并非
- 并不是
- 需要强调的是
- 换言之
- 综上
- 闭环
- 可解释、可复现、可验证
- 不是……而是……
- 具有重要意义
- 提供方向性先验

### 替换规则

| 当前写法 | 建议写法 |
| --- | --- |
| 本文并不将预测器视为真实物理求解器的替代品 | 条件预测器用于候选筛选与排序 |
| 需要强调的是 | 删除，直接说结论 |
| 换言之 | 删除或改成“因此” |
| 形成完整闭环 | 形成“预测-验证”流程 |
| 可解释、可复现、可验证 | 拆开写具体证据，不要三连 |
| 具有重要研究价值 | 写具体应用或具体困难 |
| 方向性先验 | 候选排序依据 |
| 不是 A，而是 B | 直接写 B |

### 示例

原句：

> 本文方法并不是将机器学习放在物理计算之前并取代物理计算，而是利用机器学习帮助物理搜索更有方向地使用计算预算。

改写：
