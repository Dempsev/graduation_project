# Run COMSOL Scripts

These MATLAB wrappers can start MATLAB/COMSOL or COMSOL LiveLink work. They are
not smoke tests and can be slow.

Run `scripts/check_project/check_public_layout.py` first, then read
`docs/project/COMSOL_SCRIPT_INDEX.md` and `docs/project/RUNNER_RISK_INDEX.md`
before launching these wrappers.
