# Run GA Scripts

This directory is the public entrypoint surface for target-band candidate
scoring, local refinement, validation-manifest export, and later real
COMSOL-in-loop GA wrappers.

Read `docs/project/COMSOL_SCRIPT_INDEX.md` before running MATLAB or COMSOL
wrappers. The Python wrappers added here do not launch COMSOL by themselves.
